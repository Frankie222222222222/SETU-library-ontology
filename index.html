Library Ontology

📌 Description

This ontology models a simple library system including students, librarians, books, and libraries. It demonstrates relationships such as borrowing books and managing library resources.

📚 Classes

  • Person
  • Student (Subclass of Person)
  • Librarian (Subclass of Person)
  • Book
  • Library

🔗 Object Properties

  • borrows (Student → Book)
  • worksAt (Librarian → Library)
  • locatedIn (Book → Library)

🔢 Data Properties

  • studentID
  • bookTitle

🧠 Reasoning

A reasoner was used to infer class memberships. For example, all students are automatically inferred as persons.

🔍 SPARQL Queries

The ontology includes multiple SPARQL queries to retrieve:

  • All students
  • Books borrowed by students
  • Library locations of books
